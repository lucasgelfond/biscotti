Biscotti is a self-hosted, lightweight iMessage agent. It takes a lot of inspiration from Instinct, which I loved but spooked me re perms and privacy.

I kept seeing more and more of the agent primitives (Pi harness, VM sandboxes in Firecracker, etc) open-sourced or widely available (i.e. Photon for iMessage) and figured I wouldn't need that much code to build something usable. This came together in a weekend and I'm daily driving it on my Raspberry Pi. I wanted to main as little surface area as possible so most things are plugins and it is easy to extend. Let me know what you think!
